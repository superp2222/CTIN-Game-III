# Question:
Can players, under time pressure, correctly interpret room cues and use the correct tool in the correct room to collect all evidence?

# Hypothesis (falsifiable):
Given 4 rooms with clear cues + simple visual indicators, most first-time players will collect all 3 evidences within 2 minutes without external guidance.

# What would falsify it:
If most playtesters fail (run out of time, use wrong tools repeatedly, or get lost), then the cues/UI/navigation aren’t clear enough.
